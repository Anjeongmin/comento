The headset-tomato brand mascot. Pass a mascot PNG path; optionally wrap in a soft pink halo.

```jsx
<Mascot src="assets/mascot-head-happy.png" size={122} halo />
<Mascot src="assets/mascot-happy.png" size={160} />
```

Available moods: `mascot-head-happy`, `mascot-happy` (full body), `mascot-head-sad`, `mascot-sad`. Use happy for success/onboarding, sad for empty/error states.
