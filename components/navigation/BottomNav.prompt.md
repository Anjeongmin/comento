The app's primary bottom navigation: four labelled tabs (홈 / 감정 기록 / 자막 / 돌아보기) with a raised, glowing red call FAB in the center.

```jsx
<BottomNav value={tab} onChange={setTab} onCall={startCall} />
```

Self-contained icons. Pin to the bottom of a 393px-wide screen frame. The FAB overhangs the top edge by ~22px.
