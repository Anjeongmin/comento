Surface container with the system's elevation language.

```jsx
<Card>…resting white card…</Card>
<Card variant="brand" padding={20}>오늘의 요약</Card>
<Card variant="subtle">개선할 점 본문</Card>
```

Variants: `plain` (white + hairline + soft shadow), `brand` (red gradient hero), `subtle` (gray inset), `tint`/`softtint` (red callouts). Default radius 20px (24px for `brand`).
